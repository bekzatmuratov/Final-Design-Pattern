# Strategy

Ответственный: person-2  
Рабочая ветка: `feature/person-2`

## Где используется в игре

Основной код: `src/main/java/game/Strategy.java`

Strategy считает очки разными способами. Например, обычные очки и бонусные очки за быструю езду.

## Файлы

- `PatternCode.java` - простой код паттерна Strategy
- `RunExample.java` - пример запуска

## Запуск примера

```bash
cd src/patterns/strategy
javac PatternCode.java RunExample.java
java RunExample
```
