# Decorator

Ответственный: person-2  
Рабочая ветка: `feature/person-2`

## Где используется в игре

Основной код: `src/main/java/game/Decorator.java`

Decorator добавляет машине бонусы без изменения базового класса машины: щит или множитель очков.

## Файлы

- `PatternCode.java` - простой код паттерна Decorator
- `RunExample.java` - пример запуска

## Запуск примера

```bash
cd src/patterns/decorator
javac PatternCode.java RunExample.java
java RunExample
```
