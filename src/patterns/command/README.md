# Command

Ответственный: person-2  
Рабочая ветка: `feature/person-2`

## Где используется в игре

Основной код: `src/main/java/game/Command.java`

Command превращает нажатия клавиш в команды: влево, вправо, старт, меню.

## Файлы

- `PatternCode.java` - простой код паттерна Command
- `RunExample.java` - пример запуска

## Запуск примера

```bash
cd src/patterns/command
javac PatternCode.java RunExample.java
java RunExample
```
