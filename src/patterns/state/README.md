# State

Ответственный: person-1  
Рабочая ветка: `feature/person-1`

## Где используется в игре

Основной код: `src/main/java/game/State.java`

State переключает состояние игры: готовность, игра, пауза и авария.

## Файлы

- `PatternCode.java` - простой код паттерна State
- `RunExample.java` - пример запуска

## Запуск примера

```bash
cd src/patterns/state
javac PatternCode.java RunExample.java
java RunExample
```
