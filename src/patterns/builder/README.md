# Builder

Ответственный: person-1  
Рабочая ветка: `feature/person-1`

## Где используется в игре

Основной код: `src/main/java/game/Builder.java`

Builder собирает локацию по частям: название, цена, цвета, сложность и бонусы.

## Файлы

- `PatternCode.java` - простой код паттерна Builder
- `RunExample.java` - пример запуска

## Запуск примера

```bash
cd src/patterns/builder
javac PatternCode.java RunExample.java
java RunExample
```
