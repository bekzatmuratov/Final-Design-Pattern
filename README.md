# Алматы Движ

2D игра на Java/libGDX в стиле Traffic Racer.

Главный герой — Бекзат.  
Главный соперник — Ерасыл.

В игре 10 уровней. Игрок избегает машин, проходит сюжетные сцены, догоняет Ерасыла и сражается с ним в финальном уровне.

## Запуск

Собрать проект:

```bash
mvn clean package
````

Запустить игру:

```bash
java -XstartOnFirstThread -jar target/traffic-car-2d.jar
```

## Управление

— A / Left — влево
— D / Right — вправо
— W / Up — газ
— S / Down — тормоз
— Space / Enter — старт, диалоги, выбор
— Space на 10 уровне — стрелять
— G — гараж
— Esc — меню

## Основные файлы

— Main.java — запуск игры

— Factory.java — создание объектов
— Builder.java — сборка локаций

— Command.java — управление

## Сюжет

Бекзат пытается догнать Ерасыла.

— На уровнях 1, 5 и 9 появляются сюжетные диалоги
— На уровнях 2–4 и 6–8 идёт обычная погоня
— На 10 уровне проходит финальная битва с Ерасылом
— У Ерасыла есть полоса здоровья
— Игрок должен уворачиваться от машин и стрелять по сопернику

## Цель игры

Пройти все 10 уровней, победить Ерасыла и стать лучшим гонщиком Алматы Движ.
