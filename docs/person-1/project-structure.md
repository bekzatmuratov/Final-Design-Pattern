# Person 1 - Project Structure

Person 1 is responsible for keeping the project easy to explain and safe to run.

Main areas:
- Maven setup in `pom.xml`
- run/build scripts in `scripts/`
- main Java code in `src/main/java/game`
- textures in `src/main/resources`
- pattern examples in `src/patterns`

Rules:
- do not delete working game code
- keep build command stable: `./scripts/build.sh`
- keep run command stable: `./scripts/run.sh`
